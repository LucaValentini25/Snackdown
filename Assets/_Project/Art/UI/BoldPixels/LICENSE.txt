WHAT THAT MEANS FOR THIS REPOSITORY

BoldPixels.otf is the font as published, unmodified.

"BoldPixels SDF.asset" is generated from it by TextMesh Pro: a signed-distance-
field atlas of the glyphs plus their metrics. That is an adaptation of the font,
so it carries the same licence — CC BY-SA 4.0 — and not the MIT grant that
covers this repository's source code.

Using a font to draw text does not make the thing drawing it a derivative of the
font, so nothing else here is affected. The distinction is the same one the
README already draws between the bundled art and the code.
